Fix the Android **release JS bundle** failure in the Puente Expo app so `eas build -p android --profile preview --local` completes and produces an installable standalone APK.

## Problem (confirmed from build logs)

Command that fails:

```bash
cd puente
eas build -p android --profile preview --local
```

Native Gradle configuration **already passes** (including `:onnxruntime-react-native:configureCMakeRelWithDebInfo` — the patch from prompt 003 is working). The build now fails later at the Metro embed step:

### Error 1 — ROOT CAUSE (fix this)

```
> Task :app:createBundleReleaseJsAndAssets FAILED
Failed to construct transformer: Error: Cannot find module 'babel-preset-expo'
...
code: 'MODULE_NOT_FOUND'
```

**Why:** `puente/babel.config.js` references `babel-preset-expo`, but **`babel-preset-expo` is not declared** in `package.json`. With **pnpm** strict dependency resolution (and EAS local copying the project to a temp dir), Babel cannot resolve the preset during `expo export:embed` inside the release Gradle task.

Current `babel.config.js` (already correct for Transformers.js — keep this):

```js
module.exports = function babelConfig(api) {
  api.cache(true);
  return {
    presets: [['babel-preset-expo', { unstable_transformImportMeta: true }]],
  };
};
```

### Error 2 — CASCADE (disappears after Error 1 is fixed)

```
TypeError: Cannot read properties of undefined (reading 'transformFile')
```

This is a follow-on failure because Metro never constructed its Babel transformer. **Do not debug Metro internals** — fix the missing preset first.

### Warnings — NOT build failures (do not chase unless build still fails after preset fix)

These appeared in the same log but are **informational only**:

| Log line | Action |
|----------|--------|
| `Deprecated Gradle features were used in this build, making it incompatible with Gradle 10` | **Ignore.** Comes from Expo/RN/third-party Gradle plugins on Gradle 9.3.1. Not the cause of this failure. Do not downgrade Gradle or refactor plugin code unless a task actually fails. |
| Kotlin/Java `deprecated API` notes in `react-native-safe-area-context`, `masked-view` | **Ignore.** Third-party library warnings. |
